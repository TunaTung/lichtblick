# 上位机侧可读（灵购智能购物车）

> 2026-09-06 · 自包含侧可读文档：架构、帧契约、现状、运行与验收信号全在这一页。

## 架构（一句话）
车端 ESP-01S 透传 → **TCP 8080**（bridge.py 是服务端，ESP 是客户端）→ `dashboard\bridge.py` 转 Foxglove WebSocket `ws://127.0.0.1:8765` → **Lichtblick**（桌面版=答辩主力自动导布局；web 版 127.0.0.1:8090 = 随时可看镜像，8090 被 python http.server 占着）。

## 帧契约（bridge 消费白名单，固件侧已全接）
14 种上行 JSON 帧（`{"m":"..."}`）：`st`(健康含 wifi 标志) `bat` `uw`(UWB) `imu` `pose` `ch`(四轮) `fw`(跟随,含派生 e/m) `us`(超声右/左/后) `la`(雷达36点) `dg`(诊断计数39个,追加式) `vi`(识别编号) `mode`(1跟随/2计价) `wg`(称重) `echo`(下行回声)。下行：`$q/$q-/$w/$w-/$wt/$i01..11/ack`。
桥端合成：`/health`（2Hz，数据龄 wage/报警状态机 ISA-18.2/续航估计）、`/stats`、`/prox`。

- 自检：`probe.py`（探针断言）/ `_verify_consistency.py`（16 项静态+运行时冒烟，26 项固件侧在 fw_merge_20260906\_verify_fw.py）。
- 遥控：Publish 面板 topic=/cmd 载荷 {"cmd":"$w"} 等。

## 真车验收信号（2026-09-06 固件合并+审查修复后新增）
1. **wg 帧流动**：语音"进计价"→称重仪表盘出数（此前固件分支缺 wg 帧）。
2. **bat.v 出真实电压**：不再恒 12.0（P0 修复+分压硬件核对后）；10.5V 以下"电池低电"报警灯应亮，9.5V 急停。
3. echo 帧只在短命令出现（长行不回声=正常，防流污染）。
4. UWB 精度锥随 uw.d 变宽；断流时车模变灰+wage 灯橙。
5. WiFi 心跳窗口内按钮偶发无响应=已知盲窗（约 12% 时间轴），重按即可；关键命令可加超时重发。
